# Omni-Skill MVP

Omni-Skill is a verified career evidence platform for students, esports participants, Discord/community operators, and early-career digital-native talent.

This repository starts the MVP described in `Omni-Skill_Final_Business_and_MVP_Architecture.pdf`:

- Passport profile builder
- User registration and login
- Structured evidence submission with proof upload
- Admin verification queue with approve, reject, and request-info actions
- Rule-based evidence cards and resume bullets generated only from approved facts
- Public passport page
- Basic PDF export endpoint
- Connector-ready backend structure for Discord, FACEIT, Riot, Steam, and tournament sources

## Repository Structure

```text
apps/
  api/          FastAPI backend
  web/          Next.js frontend
packages/
  shared-types/ Shared MVP contract notes/types
infra/
  docker-compose.yml
```

## Local Setup

### Backend

```bash
cd apps/api
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
uvicorn app.main:app --reload
```

The API defaults to SQLite for local development. Set `DATABASE_URL` to a Postgres URL for Supabase/Render/Fly deployments.

### Frontend

```bash
cd apps/web
npm install
copy .env.local.example .env.local
npm run dev
```

Open `http://localhost:3000`.

## First Admin

Register normally and include the admin invite code from `ADMIN_INVITE_CODE` to make that account an admin. The default local code is `omni-admin-dev`.

## MVP Notes

The current PDF export is a minimal valid PDF generated by the API without browser dependencies. The architecture keeps the `/passport/export-pdf` contract stable so it can move to Playwright HTML-to-PDF when the visual report template is ready.
